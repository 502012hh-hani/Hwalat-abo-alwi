# حوالات أبو علوي

مشروع Android أولي بواجهة عربية وخدمة استقبال إشعارات WhatsApp.

## مهم قبل الاستخدام
- هذا إصدار تأسيسي للاختبار، وليس نسخة تشغيل نهائية.
- خدمة الإشعارات لا تستطيع ضمان استخراج اسم المجموعة والمرسل في كل إعدادات واتساب؛ يعتمد ذلك على محتوى الإشعار وإعدادات الخصوصية.
- لم يُنفّذ بعد تصدير Excel الحقيقي، ولا OCR للصور. يجب اختبار شكل الإشعارات على الهاتف أولاً ثم إكمال الاستخراج والتصدير.
- لا يقرأ التطبيق سجل محادثات واتساب مباشرة؛ يعتمد على الإشعارات التي يسمح بها المستخدم.

## البناء
يتطلب Android Gradle Plugin 8.6.1 و Gradle متوافقاً و Java 17. يمكن تشغيل workflow من GitHub Actions بعد رفع ملفات المشروع إلى المستودع.
